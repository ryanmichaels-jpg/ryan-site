Junto · GTM OS · Data Layer

System Map

Every component of the planned data layer, sorted by role. Read it as a parts list for the Sources-to-Surfaces flow: triggers start work, tools hold the data, processing moves and shapes it, one decision routes it, stores keep it, outputs are where people meet it.

Triggers

what starts work
  • Rep asks in Slack@mention · thread reply (mention-to-join) · /play syntax
  • Per-connector schedulesnightly (sfdc_history) · hourly (gong_ingest) · daily (usage_shift) · weekly (harvestapi)
  • Thread goes quietfires the distiller on finished conversations

Tools

where the data lives
  • Salesforceaccounts · opps · activities · field history
  • Gongcall transcripts, by call type
  • Slackteam channels + Junto run threads
  • BigQueryproduct usage telemetry
  • External feedsHarvestAPI · Marketo · Outreach · NPS · doc-08 catalog

Processing

moves + shapes data
  • Connector jobsdeterministic: fetch since watermark → qualify → map → validate → write
  • DistillersLLM extractors: call / thread → tagged artifact, schema-validated
  • Read primitivesLLM-free queries, visibility-filtered before any model sees data
  • Synthesisevidence rows → cited answer; gaps declared, denominators shown

Decisions

routing, never silent
  • Planner over the capability catalogselects plays + sources explicitly · DISCOVER on partial match · HELP on none
  • Catalog miss → source request"no source covers NPS" → Request-this-source button → Composer form

Data stores

Postgres on the VM · every row carries visibility
  • Signals ledgercurated, attention-worthy events (frozen contract)
  • Activity rowsevery touch: emails, calls, LinkedIn, stage moves
  • Knowledge artifactsdistilled + embedded, permalinked, Pain.PointDB-tagged
  • Canonical docsread-only truth, evolved by PR
  • One retrieval indexall four project into {kind, subject, text, date, source_ref, visibility, embedding}

Outputs

where people meet the system
  • Slack replycited facts + provenance line + journey diagram + reactions
  • Composer workspaceTables · Files · Knowledge base · Sources · Logs · Pending actions · Review labeling
↻The loop that makes it compound: finished Slack threads are themselves a source — the distiller turns them into knowledge artifacts, so today's runs become tomorrow's retrievable, citable, credited context.
