The sender waits for the exact moment, then pushes the note out. The OS is juggling hundreds of other jobs, so it arrives a few milliseconds late, and a different few every time. That scatter is jitter, and you can hear it in a drum groove.

same tab, same clock booked at 3.51000

Strudel and the rack are the same JavaScript, sharing one stopwatch. So Strudel hands each note over about a second early, stamped with the exact time it is due, and the audio hardware runs it itself. Sample-accurate, zero jitter, every time.

The clock counts samples, 48,000 a second. “Play at 3.51000” means tick number 168,480, and it happens there exactly. A cable can’t do this: MIDI was built to connect machines that never share a clock, so its only word for time is now.
