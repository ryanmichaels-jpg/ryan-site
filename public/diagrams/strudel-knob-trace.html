What a knob turn actually is

One drawn circle, one number, one instant. No polling, no save button.

on the canvas
You twist a drawn knob.
a circle you sketched, blessed into a control
→
the database
A number changes in the store.
{ type: 'knob',
  cutoff: 1215 }
→
the same instant
The store fires an event.
a listener catches it,
calls engine.update()
→
the sound
A number changes on an audio node.
filter.frequency
  .value = 1215

Every shape on the canvas, even a freehand scribble, is a row in a little database: type, position, size, points. Reading your drawing is just querying it. So the picture and the sound are never two things kept in sync. They are the same number, seen twice.
